🗂️ Acceso a Carpeta de Notas

Para guardar automáticamente tus notas, necesito acceso a una carpeta en tu computadora.

Las notas se guardarán como archivos JSON y se cargarán automáticamente cuando abras el mismo PDF.

⚠️ Solo funciona en navegadores modernos (Chrome, Edge, etc.)

Informacion del visor

Navegacion:
• ← → mueve entre paginas o PDFs cuando corresponde
• ↑ ↓ hace scroll vertical
• Esc cierra modales o cancela capturas

Zoom:
• Ctrl + rueda, Ctrl + +, Ctrl + -, Ctrl + 0
• El visor intenta mantener el foco de la zona visible al acercar o alejar

Capturas:
• W abre Teoria / Practica y activa el modo captura
• Primer clic: esquina inicial. Segundo clic: esquina opuesta
• Haz clic en una captura para eliminarla antes de guardar
• Pulsa W otra vez para guardar todas las capturas

Audios anclados:
• N activa el modo para ubicar un audio en el PDF
• Haz clic en una pagina y luego graba/confirmalo en el modal
• El icono queda guardado en esa posicion y se reproduce con un clic

PDF desde capturas:
• Ctrl + M genera un PDF desde las capturas guardadas
• Elige Teoria o Practica y el visor arma el PDF automaticamente

Modo enfoque:
• F muestra u oculta la barra superior sin mover la posicion actual del PDF
